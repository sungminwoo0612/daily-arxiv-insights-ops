# 아키텍처

이 문서에서는 Daily ArXiv Insights Ops LLMOps 파이프라인의 아키텍처를 설명합니다. 이 파이프라인은 여러 가지 구성 요소로 이루어져 있으며, 각 요소는 다음과 같은 기능을 담당합니다:

1. **데이터 수집 모듈**: ArXiv 레파지토리로부터 데이터를 수집합니다.
2. **데이터 처리 모듈**: 수집된 데이터를 정제하고 변환합니다.
3. **모델 훈련 모듈**: 처리된 데이터를 기반으로 LLM 모델을 훈련시킵니다.
4. **모델 배포 모듈**: 훈련된 모델을 배포하여 사용자가 접근할 수 있도록 합니다.

이러한 모듈들은 각기 독립적으로 작동하며, 필요한 경우 서로 통신하게 됩니다.
