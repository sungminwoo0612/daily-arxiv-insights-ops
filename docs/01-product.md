# Product Direction

## Goal
개인 연구 생산성을 높이는 `paper digest + structured memory + grounded Q&A` 도구를 만든다.

## Primary User
- 개인 연구자
- AI 엔지니어
- 논문을 읽고 메모를 누적하면서 질문하는 사용자

## Design Principles
- digest-first
- local corpus first
- self-hosting minimum
- explicit research program

## External Influence
- `Khoj`: 개인 지식 검색
- `OpenPaper`: paper library와 읽기 흐름
- `autoresearch`: research program을 명시적으로 두는 운영 모델

## Non-Goals For Now
- 팀 협업 기능
- always-on observability
- 복잡한 멀티에이전트 오케스트레이션
- infra completeness 자체를 목표로 한 확장
